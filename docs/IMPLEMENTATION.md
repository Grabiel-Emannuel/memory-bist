# IMPLEMENTATION.md (docs)

Clear description of each directory's purpose, matching your repository tree. All paths are relative to the project root.

| Directory | Description (English) | Key Contents / Notes |
|-----------|---------------------|---------------------|
| log | Generated by tools (e.g., simulation logs, process output) | Binary/text logs; not edited manually. |
| report | Generated by report tool (e.g., yosys, OpenSTA, Verilator) | Contains formatted reports (area, timing, BIST metrics) as PDF/HTML/tables. |
| rtl | Behavioral SystemVerilog code (memory implementation) | Source files (*.sv) defining SRAM/DRAM modules, BIST logic, and core memory interfaces. |
| script | Helper scripts for CI/CD workflow | • Bash scripts: Makefile dependencies, environment setup, tool version checks.<br>• TCL scripts: Synthesis & timing analysis (yosys, openroad).<br>• Python scripts: Release documentation generation, UVM test harness, CD artifact creation. |
| sim | Verilator simulation artifacts | Simulation outputs (waveforms, event logs, results) generated during test execution. |
| tb | Auto-verifiable SystemVerilog test cases | Testbench modules (each a self-contained test that passes without manual assertion). |
| work | yosys workspace (synthesis environment) | Intermediate yosys outputs, temporary netlists, and synthesis configuration files. |

Example usage (referenced in Makefile):
```makefile
# Compile RTL (rtl/) → yosys output in work/
work/make_synthesis.tcl: rtl/*.sv
	yosys -o work/yosys_output.sat rtl/*.sv

# Run Verilator simulation (produces sim/artifacts)
sim/run_tests.v: sim/*.sv
	verilator -a -o sim_output/tb sim/*.sv

# Execute auto-verifiable tests (tb/)
tb/run_tests.py: tb/*.sv
	verilator -a -o tb_sim tb/*.sv && ./tb_sim --run

# Generate release documentation & reports (script/)
script/generate_release_docs.py: script/python_*.py
	python script/python_report.py --input report/results.txt --output docs/reports/release.pdf

# Produce CI/CD artifacts (all stages pass before CD)
.github/workflows/ci.yml: all
	# (defined in CI/CD section per original instructions)
```

All directories are generated automatically by tools; no manual file creation is required. The structure aligns exactly with your provided tree.
